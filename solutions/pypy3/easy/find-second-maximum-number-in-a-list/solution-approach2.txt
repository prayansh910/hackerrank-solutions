# Technique   single-pass-two-variable-tracking
# Time        O(n)
# Space       O(1)
# Insight     The algorithm maintains the two largest distinct values encountered so far by updating the second-highest score whenever a new value falls between the current first and second maximums.
# Interview   Before: "I would sort the list and pick the second to last element." After: "Sorting takes O(n log n), but we can achieve O(n) time and O(1) space by tracking the two largest distinct values in a single pass, which handles duplicate maximums correctly."
# Pitfalls    (1) Failing to handle duplicate maximum scores, which requires the strict inequality score > second to ensure only distinct values are tracked.  (2) Initializing variables to zero instead of negative infinity, which would fail if the input scores include negative integers.
# ──────────────────────────────────────────────────

if __name__ == '__main__':
    n = int(input())
    arr = map(int, input().split())
    first=second=float('-inf')
    for score in arr:
        if score>first:
            second=first
            first=score
        if score<first and score >second:
            second=score
    print(second)
