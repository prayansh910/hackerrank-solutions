# Insight     The algorithm maintains the current maximum height and its frequency in a single pass, resetting the count whenever a strictly greater height is encountered.
# Interview   Before: "I could sort the array to find the max and count it." After: "Sorting takes O(n log n), but a single-pass O(n) approach is more efficient. By tracking the max height and count simultaneously, we handle the O(n) time and O(1) space requirements optimally."
# Pitfalls    (1) Initializing maxheight to 0 is safe here because candle heights are positive integers, but it would fail if the input contained negative values.  (2) Failing to reset the count to 1 when a new maximum is found results in an incorrect frequency count.
# ──────────────────────────────────────────────────

#
# Complete the 'birthdayCakeCandles' function below.
#
# The function is expected to return an INTEGER.
# The function accepts INTEGER_ARRAY candles as parameter.
#

def birthdayCakeCandles(candles):
    maxheight=0
    count=0
    for height in candles:
        if height>maxheight:
            maxheight=height
            count=1
        elif height==maxheight:
            count+=1
    return count
